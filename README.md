# CSE Society - JNGEC Sundernagar

**Where Code Meets Innovation** 🚀

Official website of the Computer Science Engineering CSE Society at JNGEC, Sundernagar

## Live Website
🔗 https://cse-society-website.vercel.app

## About

The CSE Society is a student-led community dedicated to fostering technical excellence, innovation, and collaboration among CSE students. We provide a centralized platform for academic resources, 
technical events, career guidance, and departmental updates.

**Core Focus Areas:**
- 📚 Academic Resources (notes, exam papers, study materials)
- 💻 Technical Events (workshops, hackathons, coding competitions)
- 🎓 Career Guidance & Industry Insights
- 🤝 Community Building & Networking
- 🏆 Sports & Cultural Events

## Key Features

### Student Portal
- Access previous year exam papers
- Download study notes and resources
- Find suggestion decks for different semesters

### Events Hub
- Announcements for upcoming events
- Event details, schedules, and registration info
- Photo galleries from past events

### Official Magazine
- **Innoverse** - The CSE Society Magazine
- Features student achievements, tech innovations, and community highlights

### Community Resources
- Expert lectures & guest sessions
- Hands-on technical workshops
- Sports and cultural activities

## Getting Started (Local Development)

### Prerequisites
- A modern web browser
- A text editor (VS Code, Sublime Text, etc.)
- Git (optional, for cloning)

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/cses-jngec/cse-society-website.git
   cd cse-society-website
   ```

2. **Open locally**
   - Open `index.html` in your browser, or
   - Use a local server (recommended):
     ```bash
     python -m http.server 8000
     # or
     npx http-server
     ```

3. **Navigate to** `http://localhost:8000`

## Deployment

This project is deployed on **Vercel** and automatically updates with every push to the main branch.

To deploy your own instance:
1. Push to your repository
2. Connect to [Vercel](https://vercel.com)
3. Select this repository
4. Vercel will auto-deploy on every commit

## Contributing

We welcome contributions from CSE students and community members!

### How to Contribute

1. **Fork** the repository
2. **Create a branch** for your changes (`git checkout -b feature/your-feature`)
3. **Make your changes** and test locally
4. **Commit** with clear messages (`git commit -m "Add: feature description"`)
5. **Push** to your branch (`git push origin feature/your-feature`)
6. **Create a Pull Request** describing your changes

### Contribution Guidelines
- Keep changes focused and well-documented
- Test all updates before submitting
- Follow existing code style and structure
- Update relevant sections (event info, resources, etc.)
- Add/update images optimized for web

### Common Updates
- **Adding Events**: Edit `events.html` and upload event photos to `Photos/Events/`
- **Updating Resources**: Add files to `studentzone.html` and link appropriately
- **News/Announcements**: Update the "Latest Announcements" section on `index.html`
